# OpenCHJ国定理科教科書

明治・大正期の国定理科教科書（『尋常小学理科書』）のOpenCHJ向けデータを公開します。

## XMLファイル（TEI + Open CHJ）
- [xml](/xml)

[TEI](https://tei-c.org/)準拠のXMLファイルに[OpenCHJ XML](https://openchj.github.io/ocx.html)にあわせた修正（ルビタグの変更、文境界ocx:eosとOpenCHJ文書ルートocx:docの付与など）を行ったものです。

ocx:docの範囲だけがOpenCHJの本文として形態論情報が付与され「中納言」で検索可能になります。
